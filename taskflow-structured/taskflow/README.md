# TaskFlow – Collaborative Project Management Tool
Node.js + Express + SQLite + JWT + Socket.IO + vanilla JS frontend.

## Run
    npm install
    npm start       # http://localhost:3000   (copy .env.example to .env if you want custom values)

## Structure
    backend/   server.js, src/{config,db,realtime}.js, src/middleware, src/routes
    frontend/  index.html, css/style.css, js/*.js
